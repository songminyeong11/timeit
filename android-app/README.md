# 타임잇 Android 집중 차단 앱

타임잇 웹을 Android WebView로 열고, 웹 타이머와 네이티브 집중 차단 서비스를 연결한 설치형 앱입니다.

## 동작 방식

- 타이머 시작 시 집중 차단 서비스를 함께 시작합니다.
- 휴대폰의 앱 사용 이벤트에서 현재 실행된 앱의 패키지명만 확인합니다.
- 사용자가 허용하지 않은 앱은 타임잇 집중 화면으로 덮습니다.
- 과목을 바꿀 때는 차단을 유지하고, 타이머를 중지하면 즉시 차단을 종료합니다.
- 전화, 입력기, 시스템 권한 화면은 안전을 위해 항상 허용합니다.

## 최초 설정

앱 안에서 타이머를 처음 시작하면 다음 두 권한 설정 화면이 열립니다.

1. 앱 사용 정보 접근
2. 다른 앱 위에 표시

두 권한을 켜고 돌아오면 집중 차단이 자동으로 시작됩니다. `허용 앱` 화면에서 공부 중 사용할 앱을 선택할 수 있습니다.

## 로컬 빌드

JDK 17과 Android SDK Platform 36을 준비한 뒤 `gradlew.bat :app:assembleDebug`를 실행합니다.

Google Play 배포 전에는 별도의 영구 출시 키로 서명하고, 특수 권한 사용 사유와 개인정보 처리방침을 Play Console에 등록해야 합니다.
